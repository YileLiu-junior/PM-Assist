# 本地知识库目录

把从 Coze 导出的两个知识库文档放到这个目录，服务会自动发现并参与检索，
替代原来 Coze 云端知识库节点（dataset `7675944834888892431` 和 `7675945239978557476`）。

## Coze 导出步骤

1. 登录 coze.cn，进入工作空间 → 知识库。
2. 分别打开上面两个知识库，勾选全部文档（或逐个导出）。
3. 导出格式优先选 **.txt / .md / .csv**（本目录可直接使用）；
   如果导出为 .xlsx/.docx，请先另存为纯文本再放进来。
4. 把文件放进本目录（子目录也可以），无需重启服务，下一次任务会自动重新索引。

## 索引规则

- 支持 `.md` `.txt` `.csv` `.markdown`，按段落切成约 700 字符的片段。
- 每次任务检索 topK=5 个片段，文件名会作为「来源」显示在召回内容和证据区里。
- 以 `README` 开头或 `_` 开头的文件不参与索引。
- 检索是本地关键词加权匹配（中文字符 bigram + 词频），不调用外部 Embedding 接口；
  文档量在几百个片段以内速度没有问题。之后想换成向量检索，只需替换
  `orchestrator/knowledge.js` 里的 `search()` 实现，其他代码不用动。
